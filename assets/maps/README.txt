Put your map thumbnail files in this folder, named exactly:
  <MapName>.png
e.g. Bind.png, Ascent.png, Haven.png, Split.png, Icebox.png, Lotus.png, Sunset.png, Abyss.png, Corrode.png

These populate the map dropdowns in the control panel automatically - just drop
a new file in here and it'll show up as an option, no restart needed.
